# Offline Mail Analysis

Privacy-first локальный анализатор электронной почты. Главная цель — анализировать чувствительные письма без передачи их содержимого внешним сервисам.

## Приватность

- `.eml` обрабатывается в памяти;
- анализатор не выполняет HTTP, DNS или API-запросы;
- исходный файл приложением не сохраняется;
- найденные значения ПДн не попадают в результат;
- пути URL не сохраняются, только схема и hostname;
- имена вложений не сохраняются;
- SHA-256 вложений вычисляется локально;
- журнал содержит только технические события и уровень риска.

Для строгого режима используйте firewall/network isolation.

## Анализ

Обнаруживаются email, телефон, паспорт РФ, СНИЛС, ИНН, IBAN, IPv4, дата рождения, банковские номера с проверкой Luhn и эвристика ФИО/имени. Проверяются From/Reply-To/Received и Authentication-Results.

## Запуск

Python 3.11+. Установите зависимости: `pip install -r requirements.txt`.
Создайте парольный hash: `python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('CHANGE_ME'))"`.
Задайте `FLASK_SECRET_KEY`, `OFFLINE_MAIL_USERNAME` и `OFFLINE_MAIL_PASSWORD_HASH` как переменные окружения.
Для запуска: `python server.py`.
Интерфейс слушает только `127.0.0.1`.

## Тесты

`python -m unittest discover -s tests -v`

## Ограничения

Детектор ПДн является эвристикой и не является юридическим заключением. Приложение не может гарантировать безопасность всей ОС; для высоких требований используйте изолированную машину/VM и контроль исходящего трафика.
